# Format: Mission Data Card

## Purpose

A fillable or mission-specific page format for data that changes per mission.

## Typical sections

```txt
Aircraft / Callsign
Package
Frequencies
TACAN / ILS
Bullseye
Waypoints
Targets
Laser Codes
Datalink IDs
Loadout
TOT / Push Times
Notes
```

## Content types

Allowed:

- blank fields
- fillable rows
- compact tables
- mission-specific notes
- loadout summaries

Avoid:

- fixed aircraft procedures
- generic reference tables that do not change by mission

## Page planning

Mission data cards should be clean and writable-looking, even when exported to PNG.

Modern Unified is the best default style.

Cold War Day also works well for analog mission cards.
