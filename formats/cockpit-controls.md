# Format: Cockpit Controls

## Purpose

A visual/reference format for switch locations, HOTAS controls, cockpit panels, station responsibilities, and DCS control reminders.

## Typical sections

```txt
HOTAS Map
Cockpit Panel Map
Startup Switch Locations
Weapon Control Locations
Pilot Station
Gunner / WSO / CPG Station
DCS AI Crew Controls
```

## Content types

Allowed:

- annotated diagrams
- callout labels
- compact control tables
- station-specific cards
- DCS binding notes

Avoid:

- long normal checklist flow
- full weapons employment procedure unless tied to control operation

## Page planning

Cockpit-control pages are usually sparse because diagrams need space.

Do not shrink a cockpit map just to add more checklist rows.

## Diagram rules

- Use clear callouts.
- Keep labels short.
- Use consistent numbering or leader lines.
- If an image is used, ensure it survives PNG export clearly.
- For night styles, avoid low-contrast grey-on-black callouts.

## Era notes

### WW2

Useful for aircraft with hidden or non-obvious controls.

### Cold War

Useful for analog cockpit mode selectors, radar panels, weapon panels, and TACAN/radio controls.

### Modern

Very useful for HOTAS, MFD pages, and crew-station controls.
