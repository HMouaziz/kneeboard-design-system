# Format: Carrier Operations

## Purpose

A dedicated page format for naval launch and recovery procedures.

Use for aircraft such as F-14, F/A-18, A-4, F-4 naval variants, and future carrier aircraft.

## Typical sections

```txt
Carrier Startup Notes
Taxi / Deck Handling
Catapult Setup
Launch
Case I Recovery
Case II / III Recovery
Marshal
Landing Checklist
Bolter / Waveoff
Post-Trap
```

## Content types

Allowed:

- action rows
- speed tables
- pattern diagrams
- condition rows
- approach references
- radio/marshal mini-tables

Avoid:

- normal land-based landing unless the card intentionally compares both
- full weapons setup
- detailed navigation unrelated to recovery

## Page planning

Carrier procedures should usually not be buried inside a normal checklist if the aircraft is carrier-primary.

Common split:

```txt
Page 1: Catapult / Launch
Page 2: Case I Recovery
Page 3: Case III / Marshal Reference
```

For a simple checklist, a single carrier card can contain:

```txt
Catapult
Pattern
Trap
Bolter
```

## Key rows

```txt
Hook | DOWN
Launch Bar | DOWN / RETRACT
Wings | SWEEP / AUTO / SPREAD
DLC | CHECK
Flaps | DOWN
Speed | ON-SPEED
```

## Emphasis rules

- Hook and launch bar states are usually `critical`.
- Bolter/waveoff actions should be visually clear and not buried.
- Carrier-specific speeds should use tabular numerals.
