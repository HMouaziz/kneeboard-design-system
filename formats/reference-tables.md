# Format: Reference Tables

## Purpose

A lookup-card format for information that is not procedural but needs to be available in cockpit.

## Typical sections

```txt
Speeds
Limits
Frequencies
Threat Symbols
Abbreviations
Conversions
Weapon Codes
Radio Presets
Countermeasure Programs
Crew Commands
DCS Controls / Bindings
```

## Content types

Allowed:

- tables
- symbol legends
- short notes
- indexed lists
- small diagrams

Avoid:

- long procedures
- dense paragraphs
- unrelated tables on one page

## Page planning

Reference tables should be grouped by lookup task.

Good:

```txt
Page: Landing Speeds and Limits
Page: RWR Symbols
Page: Radio Presets
Page: Weapon Codes
```

Bad:

```txt
Page: Miscellaneous
```

## Table rules

- Use tabular numerals.
- Keep column headings short.
- Use alternating row separators only if needed.
- Avoid more than 4-5 columns unless the style supports it.
- Split huge tables over multiple pages.

## Modern note

Modern aircraft and helicopters often need many reference pages. This is not a failure of the system; it is the correct format for symbols, radios, weapon codes, and station-specific data.
