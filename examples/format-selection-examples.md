# Format Selection Examples

## Fw 190 A-8

```txt
Normal procedures -> normal-checklist
Radiator/RPM/ATA limits -> engine-management
Guns/bombs/sight -> weapons-employment
Fence in/out -> combat-fence
```

## Spitfire Mk IX

```txt
Prestart/start/takeoff/landing/shutdown -> normal-checklist
Boost/RPM/temp limits -> engine-management
Mark II gunsight and bombing -> weapons-employment
```

## F-5E Tiger II

```txt
Start/taxi/takeoff/landing/shutdown -> normal-checklist
Armament panel/master arm -> combat-fence
Guns/missiles/bombs/rockets -> weapons-employment
TACAN/radio/altimeter -> navigation
```

## MiG-21bis

```txt
Start/taxi/takeoff/landing/shutdown -> normal-checklist
Radar/SPO/navigation setup -> sensors-and-avionics or navigation
Missiles/guns/rockets/bombs -> weapons-employment
Engine/afterburner/restart -> engine-management or emergency
```

## Mirage F1

```txt
Normal flow -> normal-checklist
Radar and weapons modes -> sensors-and-avionics + weapons-employment
Navigation radio and altimeter conversions -> navigation/reference-tables
```

## F-14 Tomcat

```txt
Startup/takeoff/landing/shutdown -> normal-checklist
RIO/radar/TID/Datalink notes -> sensors-and-avionics
Phoenix/Sparrow/Sidewinder/gun -> weapons-employment
Carrier launch/recovery/trap -> carrier-operations
```

## F-16C Viper

```txt
Cold start/taxi/takeoff/landing/shutdown -> normal-checklist
Fence in/out -> combat-fence
MFD/HOTAS/sensors -> sensors-and-avionics
A-A and A-G weapons -> weapons-employment
Datalink/TACAN/waypoints -> navigation/mission-data-card
```

## AH-64D

```txt
Startup/shutdown -> normal-checklist
Pilot/CPG station references -> cockpit-controls
TADS/PNVS/IHADSS/FCR -> sensors-and-avionics
Hellfire/rockets/gun -> weapons-employment
Symbols/codes/radios -> reference-tables
Mission-specific freqs/codes -> mission-data-card
```
