# Example Page Plan: Fw 190 A-8 Anton

## Source

Existing one-page Anton quick checklist PNG plus Spitfire-style visual inspiration.

## Target

```txt
Aircraft: Fw 190 A-8
Era: WW2
Style: WW2 Day
Output: HTML then PNG
```

## Recommended pages

### Page 1: Normal Checklist

Format: `normal-checklist`

Sections:

```txt
Before Start
Engine Start
Engine Warmup
Before Takeoff
After Takeoff
Landing
Shutdown
```

Notes:

- Keep the starter clutch row critical.
- Keep throttle/fuel lever shutdown row critical.
- Optional/DCS/less relevant rows can be muted.
- Preserve German cockpit state labels where useful: AUF, ZU.

### Page 2: Combat / Weapons

Format: combined `combat-fence` + `weapons-employment` if keeping page count low.

Sections:

```txt
Fence In
Fence Out
Gunsight
Bombing
```

Notes:

- If more weapons content is added later, split combat fence and weapons into separate pages.
- Bombing diagram should use WW2-style black line art.

### Optional Page 3: Engine Management

Format: `engine-management`

Sections:

```txt
Power Settings
Temperature Limits
Radiator Notes
Fuel Notes
```

This page is useful if moving from a minimal DCS checklist to a more serious warbird kneeboard.
