# Archetype: Punched Technical Order

## Artifact

A checklist or reference sheet removed from a military ring binder.

## Grammar

- visible binding spine and punched holes
- equipment-data header and issue block
- stencil bands and numbered procedure cards
- monospaced values
- stamped critical actions

## Suitable Uses

Early jet and Cold War procedure sets associated with formalized technical
orders and squadron checklist binders.
