# Style: Cold War Day

## Purpose

A daylight kneeboard style for early jets, analog cockpits, and Cold War strike/fighter aircraft.

Use for:

- F-86
- MiG-15
- F-5E
- MiG-21bis
- Mirage F1
- AJS-37
- F-4
- F-14
- early A-10

## Visual character

```txt
laminated checklist + technical flight manual extract
```

Less romantic than WW2, more utilitarian and technical.

## Palette

Recommended semantic palette:

```txt
background: off-white / pale grey / faded checklist card
text: black or dark charcoal
muted text: medium grey
section header: black, dark navy, or dark olive
section header text: white
accent: muted yellow, orange, blue, or olive depending aircraft/faction
critical: yellow or amber row marker
warning: black/yellow or red/orange label, used sparingly
borders: dark grey
```

Avoid:

- parchment-heavy WWII texture
- ultra-modern glass UI styling
- colorful dashboards

## Typography

Cold War should look sharper and more technical than WWII.

Recommended:

- condensed sans-serif headings
- monospaced or tabular numerals for tables
- compact action rows
- uppercase acronyms preserved

## Layout

Best suited for:

- two-column checklist pages
- compact tables
- boxed subpanels
- technical reference blocks
- mode/procedure cards

Default page anatomy:

```txt
Header
  aircraft | page title | mode/day chip
Body
  gridded section cards
Footer
  page number and optional module/version note
```

## Row behavior

Use dotted leaders or strong value alignment. Cold War pages can be more grid-like than WW2.

Common row types:

```txt
Switch ............. ON
Mode ............... STBY / OPER
Frequency .......... SET
Radar .............. AS REQ.
```

## Emphasis mapping

```txt
normal: dark text
muted: grey text
optional: grey text with optional tag
critical: amber/yellow left strip or filled row
warning: boxed warning label
caution: thin amber marker
```

## Era-specific behavior

Cold War jets often require format separation for:

- radar/sensor setup
- weapon selector configuration
- navigation radios/TACAN
- takeoff/landing speed references
- carrier operations for naval aircraft
- engine limits and relight procedures

Do not cram all of this into normal checklist.

## Best format matches

- normal-checklist
- combat-fence
- weapons-employment
- sensors-and-avionics
- navigation
- carrier-operations
- engine-management
- emergency
- reference-tables
