# Style: WW2 British Day

Version: 1.0

## Purpose

A daylight RAF working-document style for British WWII aircraft such as the
Spitfire. It implements the shared rules in `ww2-base.md`.

## Visual Character

```txt
Air Ministry Pilot's Notes + RAF Form 700 ledger + squadron annotations
```

The page should resemble an issued flying document adapted for cockpit use:
cool service stock, docket fields, typed entries, filing tabs, inspection
marks, and restrained RAF identification.

## Palette

```txt
paper: cool blue-grey/off-white service stock
primary ink: blue-black
secondary ink: graphite blue-grey
form rules: faded RAF blue
origin colors: roundel blue / warm white / muted red
critical mark: red inspection pencil
warning: double blue rule with red pencil notation
```

Avoid yellow parchment, saturated royal blue, glossy effects, modern card
panels, and copying the German registration-header treatment.

## Origin Marks

- Use a simplified RAF Type C-style roundel at kneeboard scale.
- Use `AIR MINISTRY`, `PILOT'S NOTES`, or a short form/document number as
  restrained docket text.
- A narrow blue/white/red filing stripe may appear once.
- Avoid crowns, coats of arms, and oversized flags.

## Typography

- Aircraft and page titles use a sturdy book serif.
- Pre-printed labels use a humanist sans-serif resembling British transport and
  technical lettering.
- Entered values and notes use a typewriter face.
- Do not use handwriting fonts.

## Layout

```txt
issue header: roundel | aircraft | Air Ministry docket
double-underlined page purpose
open ledger columns with filing-tab section legends
footer: source | sheet number | issue
```

Sections should feel like entries on one continuous form. Use open edges,
double rules, short tab labels, and occasional check marks instead of repeated
boxed cards.

## Emphasis

```txt
normal: blue-black typed entry
muted: graphite note
critical: red pencil side tick and underline
warning: double blue rule plus red notation
secondary callout: dashed filing note
```
