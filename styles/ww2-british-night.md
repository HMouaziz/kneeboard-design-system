# Style: WW2 British Night

Version: 1.0

## Purpose

A low-glare counterpart to `ww2-british-day.md`.

## Visual Character

```txt
RAF issued flying form under dim red cockpit illumination
```

The document grammar, page breaks, section order, and docket fields remain
identical to the day version.

## Palette

```txt
paper: dark slate-grey with a muted blue cast
primary ink: warm low-luminance ivory
secondary ink: muted khaki-grey
form rules: subdued steel blue-grey
origin colors: heavily dimmed roundel blue / ivory / oxide red
critical mark: dusty red pencil
warning: double slate rule with restrained red notation
```

Avoid pure black, bright white, luminous orange, and simple palette inversion.

## Typography And Layout

Use the same typography and Air Ministry ledger grammar as the day style.
Texture should be reduced, while thin rules and helper notes may be slightly
brighter for cockpit readability.

## Design Rule

The night page should feel like the same issued sheet prepared for low-light
use, not a modern dark interface.
