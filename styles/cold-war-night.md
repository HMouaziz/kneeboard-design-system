# Style: Cold War Night

## Purpose

A low-glare night style for Cold War jets and analog/early-digital cockpits.

Use for night versions of F-5E, MiG-21, Mirage F1, AJS-37, F-4, F-14, and similar aircraft.

## Visual character

```txt
night cockpit checklist + phosphor/amber technical card
```

This should feel more instrument-panel-like than WW2 Night.

## Palette

Recommended semantic palette:

```txt
background: dark slate / dark green-black / charcoal
panel background: slightly lighter dark grey/green
text: pale green, warm amber, or low-glare off-white
muted text: desaturated grey-green
section header: very dark panel strip
section header text: pale green/amber
accent: phosphor green or amber
critical: amber or yellow-green marker
warning: amber/red-orange outline, used sparingly
borders: dim green-grey
```

Avoid:

- pure black + pure white
- blue-heavy modern UI styling
- WW2 parchment texture

## Typography

- technical condensed sans-serif
- tabular numerals for speeds/frequencies
- compact but readable
- stronger table support than WW2 Night

## Layout

Cold War Night should keep the same section grammar as Cold War Day but use:

- less fill brightness
- more outlines
- stronger row separation
- slightly larger values if needed

## Emphasis mapping

```txt
normal: pale green/amber/off-white
muted: dim grey-green
optional: dim grey-green with optional tag
critical: amber marker or boxed row
warning: amber/red-orange border and label
caution: thin amber side marker
```

## Best format matches

- normal-checklist
- combat-fence
- weapons-employment
- sensors-and-avionics
- navigation
- carrier-operations
- reference-tables
- emergency
