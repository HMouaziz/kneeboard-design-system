# Style: WW2 German Night

Version: 2.0

## Purpose

A low-glare counterpart to `ww2-german-day.md`.

## Visual character

```txt
German field form under dim red-amber cockpit illumination
```

It preserves the same form rules, registration marks, page breaks, and document
logic as the day version.

## Palette

Recommended semantic palette:

```txt
paper: very dark field-grey with a slight green cast
primary ink: low-luminance warm grey/amber
secondary ink: readable muted khaki-grey
form rules: subdued olive-grey
origin colors: heavily dimmed black / ivory / oxide red
critical mark: restrained oxide-red outline and hatch
warning: double olive-amber rule
```

Avoid:

- pure black with pure white text
- luminous amber or orange
- filled modern cards
- heavy texture that reduces legibility

## Typography

Use the same typography and form grammar as WW2 German Day.

Differences:

- slightly larger text may be needed
- more spacing between sections
- avoid ultra-thin fonts

## Layout

Use the same page grammar and origin marks as WW2 German Day.

Differences:

- less paper texture
- thicker row spacing if contrast is lower
- use outlines instead of filled highlights where possible

## Emphasis mapping

```txt
normal: warm grey typed entry
muted: khaki-grey note
critical: oxide-red side rule plus low-contrast hatch
warning: double olive-amber stamped box
caution: short oxide-red margin mark
```

## Design rule

Do not invert the day palette. Simulate a dark field document adapted to dim
cockpit illumination, with origin colors remaining identifiable but subdued.
