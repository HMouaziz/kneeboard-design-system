# Style: WW2 Night

## Purpose

A low-glare nighttime variant of the WWII kneeboard style.

Use for WWII night flying, dusk missions, low cockpit brightness, or VR readability when a paper-white kneeboard is too bright.

## Visual character

```txt
dim cockpit card + red/amber-filter friendly notes
```

It should still feel WWII, but without the bright parchment background.

## Palette

Recommended semantic palette:

```txt
background: deep charcoal / dark brown-black
panel background: slightly lighter charcoal
text: warm cream or dim amber
muted text: low-contrast warm grey
section header: black
section header text: amber/cream
accent: muted amber
critical: amber highlight or outlined strip
warning: stronger amber/yellow border
borders: low-glare warm grey
```

Avoid:

- pure black with pure white text
- neon green unless intentionally doing a later Cold War style
- bright yellow blocks that destroy night adaptation
- heavy texture that reduces legibility

## Typography

Same typography family as WW2 Day if possible.

Differences:

- slightly larger text may be needed
- more spacing between sections
- avoid ultra-thin fonts

## Layout

Use the same page grammar as WW2 Day.

Differences:

- less paper texture
- thicker row spacing if contrast is lower
- use outlines instead of filled highlights where possible

## Emphasis mapping

```txt
normal: warm cream/amber text
muted: dim warm grey
optional: dim warm grey with optional tag
critical: amber boxed row or soft amber fill
warning: strong amber border and warning label
caution: amber side marker
```

## Design rule

Do not simply invert WW2 Day. Night style needs lower glare, not just dark mode.
